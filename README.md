# Repo Pulse

The vital signs of any public GitHub repository, in a black and white glass interface.

## Features
- Search by `owner/repo` or a GitHub link
- Summary: stars, forks, watchers, license, last updated
- Commits per week for the last year
- Open vs. closed issues, language breakdown, top 5 contributors
- Health score out of 100 with a breakdown
- Invert (light) mode and recent searches saved in your browser

## Run it
Open `index.html` in a browser. No build step.

## Deploy on GitHub Pages
1. Push these files to a public repo.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME`.

## Health score
Recent activity (30), issues resolved (25), contributors (20), README (15), license (10).

## Notes
Uses the unauthenticated GitHub API, which allows 60 requests per hour per IP.
